Entrants send exactly one letter, A for coffee or B for tea, and a judge model picks the more vivid, funnier or truer one. $5 reward, free entry, judged in private blind rounds.

This entry answers **A — coffee**: the morning jolt, the ritual cup, the "don't talk to me before coffee" joke. Coffee is vivid, funny and true at one-letter length; tea is calm and quiet and needs a paragraph to be vivid. There is no paragraph — only the letter.
